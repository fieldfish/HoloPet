# 隐私与数据边界

HoloPet 会接触麦克风音频、对话文本、云端模型凭据和可选的本地偏好数据。部署者必须明确这些数据的流向。

## 不进入仓库的内容

- API Key、Authorization Header、Cookie 或真实 `.env`；
- 原始 WAV/PCM、真实对话正文和屏幕录制；
- SQLite 记忆数据库；
- IP、用户名、热点、VPN 与设备唯一标识；
- 模型权重、私有字体和供应商下载包；
- 实机验收证据与个人操作日志。

## 运行时原则

- Key 仅通过环境变量或权限受控的系统文件注入；
- 临时音频使用受限权限，完成或取消后清理；
- 审计默认只记录事件、长度、哈希和稳定错误码；
- 本地模式必须禁止云端 Provider 请求；
- 偏好记忆应由用户显式触发并可列出、删除；
- 公开问题报告前必须删除设备路径、IP 和对话内容。

## Provider 责任

启用云端 ASR、LLM 或 TTS 时，数据会按配置发送至相应服务商。部署者应阅读服务商隐私政策、选择合适区域，并在使用前取得录音参与者同意。

# 硬件说明

## 参考配置

- Raspberry Pi 5；
- 800×800 DSI 圆形屏，外径约 115 mm；
- EC11 旋转编码器模块；
- USB 声卡或 USB 音频转接器；
- 单声道麦克风；
- 两只约 70×30×20 mm 扬声器；
- OD90 / ID86 / H180 mm 玻璃罩；
- 符合 Raspberry Pi 5 负载需求的稳定电源。

不同批次模块的尺寸、引脚标记和声卡设备名可能不同。打印完整外壳前，应先测量实物并打印配合样件。

## EC11 默认映射

软件默认配置使用：

| 信号 | BCM GPIO |
|---|---:|
| A | 27 |
| B | 17 |
| SW | 22 |

EC11 模块的 A/B 标签可能与旋转方向预期相反。优先通过配置中的 `invert_direction` 修正方向，不要在设备通电时改线。VCC 应按模块电平要求连接，GPIO 不得承受 5 V。

## 音频

ALSA 设备名依系统枚举结果配置。先使用 `arecord -l` 和 `aplay -l` 确认采集/播放设备，再填写示例配置。不要依赖固定的 `card 0` 编号。

## 屏幕和字体

显示运行时使用 SDL2/SDL2_ttf。中文界面需要系统安装含 CJK 字形的字体；仓库不分发第三方字体。圆屏方向、可视安全区和玻璃罩遮挡需要在最终装配状态下校准。

## 安全提示

- 断电后再接插 DSI、GPIO、扬声器和音频线；
- 确认功放和扬声器阻抗/功率匹配；
- 不让裸露焊点接触 Pi、屏幕背板或金属紧固件；
- 外壳应保留散热和线缆弯曲空间；
- 机械模型不是电气安全认证文件。
